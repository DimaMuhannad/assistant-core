<objective>
Переключить CLI-аудит (hook, гейт, ручной запуск) на данные `persona.yaml`, не ослабляя ни hook, ни shield (SECF-01, D-06..D-10, D-21).

Purpose: библиотека (план 02-06) уже умеет принимать данные пространств. Обёртка assistant-core должна их загрузить и передать; fail-closed при любой проблеме с данными. Известное следствие, зафиксированное решением владельца D-21 после проверки планов: pre-commit hook блокирует любой коммит, затрагивающий `config/persona.yaml`, потому что файл объявляет слова NDA (три «известных ложных срабатывания» гейтов). Hook и shield из-за этого НЕ ослабляются (безопасность только ужесточается): никакого допуска объявленных слов персоны нет ни в режиме фиксации, ни в режиме `--all`. Коммит `config/persona.yaml` в этой фазе делается разовым `git commit --no-verify` только после явного согласия владельца (чекпоинт плана 02-11, единственная правка файла персоны в фазе). Полные аудиты (`--all`: оба гейта, web-аудит) видят те же три известные находки, поэтому замороженные списки гейтов и гейт chat-app (его правка запрещена решением D-15 Phase 1) остаются верными.

Output: переписанная обёртка, тесты CLI, переписанный тест паритета и тест синтетической персоны. Порядок: план идёт ПОСЛЕ правки chat-app (07), потому что прежний тест chat-app P03 сравнивал sha256 копий обёртки.

Исполнитель — Claude (логика NDA, fail-closed, hook).
