3. `scan_file_content(rel_path, text, *, keywords=())` со следующим поведением, строго в этом порядке. (а) Запрещённое имя: вернуть список из одной находки kind=«forbidden_file», name = последний компонент пути, line=0, текст не разбирать. (в) Слова NDA: текст делится по «\n» (то же правило нумерации, что у секретов, `splitlines` не использовать); для каждой строки и каждого непустого после `strip` слова сравнение через `casefold` с обеих сторон; одна находка kind=«keyword» на пару (строка, слово) с name = слово как передано; допуска вхождений нет ни для одного файла: каждое вхождение есть находка (D-21, проверка слов не ослабляется). 4. `format_cli(display_path, finding)` возвращает прежние строки CLI: для запрещённого файла «Forbidden file pattern committed: {name}»; для секрета «{display_path}:{line} - Found potential {name}»; для слова «{display_path}:{line} - Found proprietary corporate keyword '{name}' in public repository!».
