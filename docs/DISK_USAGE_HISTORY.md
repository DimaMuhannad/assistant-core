# История использования дискового пространства сервера

Данный документ фиксирует хронологические срезы использования дискового пространства на боевом сервере (`89.125.8.69`). Используется для отслеживания динамики роста кэшей, логов, данных и планирования очистки при исчерпании места.

---

- **Сервер:** `89.125.8.69` (Ubuntu 24.04 LTS)

### Потенциальные точки безопасной очистки (~1.9 GB)
1. `apt-get clean` — освобождает **~388 MB**.
2. Удаление `/opt/assistant-core/sqlite+aiosqlite:` — освобождает **~236 MB** (временные тестовые артефакты).
3. `npm cache clean --force` — освобождает **~585 MB**.
4. `pip cache purge` — освобождает **~195 MB**.
5. Отключение и удаление дублирующего `/swapfile` (512 MB) — освобождает **~513 MB**.
